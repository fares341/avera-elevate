Build an ultra-luxurious, editorial full-stack website for "AVERA" — an elite brand umbrella uniting luxury wedding planning (Avera Wedding House) and corporate event production (Millions Event).

CRITICAL DESIGN RULE: STRICT LIGHT LUXURY PALETTE (NO DARK MODE / NO BLACK BACKGROUNDS)

- Surfaces & Cards: Clean white (#FFFFFF) with subtle warm stone borders (#E7E5E4).
- Text & Titles: Deep charcoal / espresso (#1C1917) in high-contrast editorial Serif (Playfair Display or Cormorant Garamond).
- Body Font: Elegant Sans-serif (Inter) in warm muted slate (#44403C).
